# 首经贸留学助手作品设计书

## 一、作品名称

首经贸留学助手

副标题：AI 驱动，基于真实案例的首经贸专属留学选校分析系统

## 二、作品定位

本作品是一款面向首都经济贸易大学普通本科生的留学选校网页应用。系统聚焦通过高考进入首经贸的本科生，在毕业申请海外硕士时常见的选校、定位、案例参考和时间规划问题。

作品不面向国际本科、2+2、预科、留学基地等项目路径，避免将不同录取背景的数据混合使用，从而提升选校建议的针对性和可信度。

## 三、设计背景

首经贸学生在申请海外硕士时通常会遇到几个问题：

1. 不清楚自己的 GPA、语言成绩、实习背景对应什么层次的学校。
2. 网络上的留学案例来源混杂，难以判断是否适用于首经贸普通本科背景。
3. 留学中介给出的选校方案不透明，学生难以理解冲刺、匹配、保底的划分依据。
4. 同一名学生可能同时考虑英国、香港、新加坡、澳大利亚、美国、日本、韩国等多个地区，需要一个更清晰的对比入口。
5. 大模型可以辅助分析，但不能直接编造录取案例或虚构学校录取数据。

因此，本作品将“规则系统”和“AI 分析”分开设计：先用本地案例库和规则系统生成学校推荐，再由 AI 基于已有推荐结果进行解释和补充分析。

## 四、设计目标

### 4.1 产品目标

- 建立首经贸学生专属的海外硕士选校辅助工具。
- 将学生背景填写、案例匹配、学校推荐、时间规划整合到一个页面中。
- 让学生快速获得冲刺校、匹配校、保底校三档建议。
- 为每所学校提供中文名、英文名、官网链接和招生链接。
- 保留后续接入真实案例 Excel、数据库和 AI API 的扩展空间。

### 4.2 用户目标

- 学生可以快速填写个人学业背景。
- 学生可以选择多个目标国家或地区。
- 学生可以获得可解释的学校推荐结果。
- 学生可以通过官网链接进一步核对项目要求。
- 学生可以在 Vercel AI 版中使用 DeepSeek 进行深度分析。
- 学生可以在无 AI 静态版中使用本地规则报告，避免后端部署限制。

## 五、目标用户

主要用户：

- 首经贸普通本科大三、大四学生
- 有海外硕士申请计划的学生
- 对金融、会计、商业分析、管理、经济、数据科学等方向感兴趣的学生

次要用户：

- 辅导员、班主任、学院升学指导老师
- 留学规划社群或学生组织
- 后续维护案例库的运营人员

## 六、核心功能设计

### 6.1 使用介绍页

用户首次进入页面时，会看到多页滑动式介绍。介绍内容包括：

- 产品服务对象
- 不混淆国际本科路径
- 如何填写学业背景
- 如何生成选校结果
- 如何理解冲刺、匹配、保底
- 如何使用 AI 或本地分析报告

该设计降低了新用户的理解成本，也符合移动端轻量引导的使用习惯。

### 6.2 登录注册 UI

系统提供登录/注册弹窗 UI，但当前版本不进行真实鉴权。该模块用于后期扩展：

- 保存用户背景档案
- 保存历史选校方案
- 上传或管理个人材料
- 接入案例贡献与审核流程

当前版本允许用户关闭登录弹窗并直接进入选校界面，保证核心功能不被登录流程阻塞。

### 6.3 学业背景填写表单

表单字段包括：

- 本科专业
- GPA
- 语言考试类型
- 语言分数
- 目标国家或地区
- 预算范围
- 实习经历
- 科研或学术成果
- 目标专业方向

其中，本科专业使用首经贸本科专业下拉选择，避免自由填写造成数据不规范。语言考试支持雅思、托福、多邻国、PTE、六级、暂未考试等选项，并按考试类型提供对应分数选择。目标国家或地区使用旗帜加名称的多选按钮，用户可以自主选择英国、香港、新加坡、澳大利亚、美国、日本、韩国、加拿大、法国、德国、荷兰、瑞士等地区。

实习经历和科研成果采用文本框，让用户自行描述真实经历。

### 6.4 学校推荐结果

系统输出三档学校：

- 冲刺学校
- 匹配学校
- 保底学校

每个学校卡片展示：

- 学校中文名
- 学校英文名
- 国家或地区
- 推荐项目
- 申请成功率估计
- 推荐理由
- 学校官网按钮
- 项目或招生链接按钮

如果学校链接暂未补充，界面显示“官网待补充”，不影响页面运行。

### 6.5 首经贸案例库

当前版本使用 JSON mock 数据保存 35 条案例。案例字段包括：

- 学生标签
- 本科专业
- GPA
- 语言成绩
- 目标地区
- 目标方向
- 录取学校
- 录取项目
- 案例层级
- 背景描述
- 年份
- 来源类型

案例库设计原则：

- 优先使用普通本科路径案例。
- 不纳入国际本科、2+2、预科等路径。
- 缺少真实样本时允许使用 mock 样本占位，但需要在来源类型上标记。
- 后期可接入 Excel 或数据库进行维护。

### 6.6 DeepSeek AI 分析助手

Vercel AI 版提供 DeepSeek 分析模块。用户生成推荐结果后，可以点击“让 DeepSeek 深度分析”。

AI 分析内容包括：

- 当前背景优势
- 当前短板
- 冲刺校风险
- 匹配校建议
- 保底校建议
- 申请材料提升方向
- 时间规划

AI 的输入仅包括：

- 用户填写的背景
- 当前规则系统推荐出的学校
- 本地案例库数据

AI 不能直接编造学校录取数据，也不能虚构案例。如果案例库没有对应样本，必须明确提示“案例库暂无对应样本”。

### 6.7 无 AI 静态版分析报告

由于国内平台部署和海外平台访问存在限制，系统保留无 AI 静态版。

无 AI 版特点：

- 不需要后端
- 不需要 API Key
- 可部署在 GitHub Pages
- 点击按钮后由前端本地规则生成分析报告
- 适合作为公开演示版本和低成本备用版本

## 七、推荐逻辑设计

当前推荐逻辑为规则系统，不直接依赖大模型。

主要规则维度：

- GPA 水平
- 语言成绩
- 目标国家或地区
- 预算范围
- 本科专业
- 目标方向
- 实习经历
- 科研或竞赛经历
- 本地案例相似度

推荐过程：

1. 读取用户背景。
2. 在案例库中寻找相似方向和相似地区案例。
3. 根据 GPA、语言成绩和背景完整度计算基础竞争力。
4. 将学校划分为冲刺、匹配、保底三档。
5. 从学校数据库中匹配学校官网和招生链接。
6. 输出推荐理由、成功率估计、补充材料建议和时间规划。

规则系统的优点：

- 逻辑透明
- 结果可控
- 便于测试
- 便于后期和真实案例库结合
- 不会因为大模型幻觉直接生成虚假录取数据

## 八、界面设计说明

### 8.1 视觉风格

界面采用现代化、多层 UI 设计，整体风格简洁、克制、清晰。页面避免 Coze 默认模板感，改为独立的产品化界面。

主要设计特点：

- 左侧为学业背景表单
- 右侧为选校分析结果
- 顶部保留产品名称和简短定位
- 右上角提供更多菜单
- 结果区采用分层卡片展示
- 学校卡片强调学校名称、成功率和访问官网按钮

### 8.2 移动端适配

移动端采用单列布局：

- 顶部显示产品名称和菜单按钮
- 表单优先展示
- 国家地区按钮自动换行
- 结果区向下排列
- 卡片保持足够点击区域

### 8.3 交互设计

主要交互路径：

1. 用户进入首页。
2. 查看滑动介绍。
3. 关闭或跳过登录弹窗。
4. 填写学业背景。
5. 选择目标国家或地区。
6. 点击“生成可去学校”。
7. 查看冲刺、匹配、保底学校。
8. 点击官网或项目链接进一步核对。
9. 在 Vercel 版中点击 DeepSeek 分析，或在静态版中生成本地报告。

## 九、技术架构

### 9.1 前端技术

- React
- TypeScript
- Tailwind CSS
- Vite
- lucide-react 图标库

### 9.2 数据层

- `src/data/formOptions.ts`：表单选项
- `src/data/offerCases.ts`：本地案例库
- `src/data/schoolDatabase.ts`：学校官网与招生链接数据库

### 9.3 业务逻辑层

- `src/lib/recommendation.ts`：规则推荐逻辑
- `src/lib/recommendation.test.ts`：推荐逻辑测试

### 9.4 组件层

- `IntroCarousel.tsx`：使用介绍
- `AuthModal.tsx`：登录注册 UI
- `ProfileForm.tsx`：学业背景表单
- `ResultPanel.tsx`：推荐结果和分析报告

- `api/deepseek-analysis.ts`
- 从环境变量读取 `DEEPSEEK_API_KEY`

- 使用模型 `deepseek-chat`

EdgeOne 适配：

- `cloud-functions/api/deepseek-analysis/index.ts`
- 用于后续国内平台部署

## 十、部署方案

### 10.1 Vercel AI 版

地址：

```text
https://cueb-study-abroad-assistant.vercel.app/
```

特点：

- 支持 DeepSeek AI 分析
- 后端安全保存 API Key
- 适合展示完整 AI 功能
- 中国大陆访问可能不稳定

环境变量：

```env
DEEPSEEK_API_KEY=你的 DeepSeek Key
VITE_ENABLE_DEEPSEEK=true
```

### 10.2 GitHub Pages 无 AI 版

地址：

```text
https://liu061231-code.github.io/cueb-study-abroad-assistant/
```

特点：

- 纯静态部署
- 不需要 API Key
- 使用本地规则分析报告
- 适合公开展示和备用访问

构建环境变量：

```env
VITE_ENABLE_DEEPSEEK=false
```

## 十一、安全设计

安全原则：

- DeepSeek API Key 不进入前端代码。
- Vercel 版通过 Serverless API 调用 DeepSeek。
- GitHub Pages 版不调用后端 API。
- AI 分析只基于已有数据，不允许编造录取案例。
- 外部链接使用 `target="_blank"` 和 `rel="noopener noreferrer"`。
- 如果接口返回异常，前端显示错误提示，而不是直接崩溃。

## 十三、创新点

1. 面向首经贸普通本科生的垂直选校工具，而不是泛留学聊天机器人。
2. 将规则推荐和 AI 分析分离，避免大模型直接编造学校结果。
3. 使用首经贸案例库作为推荐依据，强调背景相似性。
4. 支持多国家和地区同时选择，适应真实混合申请场景。
5. 保留 Vercel AI 版和无 AI 静态版两种形态，兼顾功能完整性和访问可用性。
6. 学校推荐结果直接附官网与招生链接，便于用户核对信息。

## 十四、当前限制

- 案例库仍为 mock 数据与部分公开案例混合，真实样本数量不足。
- 成功率估计基于规则系统，不代表实际录取概率。
- DeepSeek AI 版依赖 Vercel，国内访问可能不稳定。
- 登录注册模块目前仅为 UI 占位。
- 尚未接入真实数据库和后台管理系统。
- 目标专业暂只覆盖金融、会计、商业分析、管理、经济、数据科学。

## 十六、总结

首经贸留学助手不是一个简单的聊天机器人，而是一个面向具体学校、具体学生群体和具体申请场景的选校分析系统。作品通过结构化表单收集背景信息，用规则系统生成稳定可解释的推荐结果，再通过 DeepSeek 或本地规则报告提供进一步分析。

当前版本已经具备完整的前端体验、案例库、学校链接库、规则推荐、AI 接口和双版本部署方案。后续如果接入真实案例 Excel、数据库和用户系统，可以进一步发展为首经贸学生专属的海外硕士申请辅助平台。
